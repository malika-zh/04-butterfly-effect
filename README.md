# Chaos Theory & Butterfly Effect Simulation (Lorenz Attractor)

A computational physics project visualizing deterministic chaos and the Lorenz system of differential equations in 3D phase space.

## Core Mechanics
- Numerical integration of non-linear differential equations (Euler/Runge-Kutta methods).
- Demonstrates sensitive dependence on initial conditions (the famous Butterfly Effect).
- Built using Python, NumPy, and Matplotlib for 3D trajectory plotting.

## How to Run
```bash
pip install numpy matplotlib
python butterfly_effect.py
